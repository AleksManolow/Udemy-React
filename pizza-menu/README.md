# 🍕 Fast React Pizza Co.

A simple pizza restaurant menu application built with React as part of **The Ultimate React Course** by Jonas Schmedtmann.

## Screenshot

![Pizza Menu](https://github.com/user-attachments/assets/7d6cf32b-b473-4050-abfb-766854279b0d)

## Features

- Display pizzas with images, ingredients, and prices
- Dynamically render the restaurant menu
- Display the number of available menu items
- Highlight sold-out pizzas
- Display restaurant opening hours
- Conditionally display the order section

## Technologies Used

- React
- JavaScript (ES6+)
- JSX
- CSS

## What I Learned

- React fundamentals
- Creating reusable components
- JSX syntax and rules
- Passing data through props
- Destructuring props
- Rendering lists with `map()`
- Using unique keys in lists
- Conditional rendering with `&&` and ternary operators
- Applying CSS classes dynamically
- Component composition

## Getting Started

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```
